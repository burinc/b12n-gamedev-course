# Course demos

Every game you build in the course, running from this repo's own `exercises/` code on its own vendored raylib engine. Recorded with [screen-grab](https://github.com/burinc/b12n-screen-grab); regenerate with `bb record`.

## 🎈 Phase 1 — Foundations

### bouncing-ball

The first thing that moves: one ball, one velocity vector, walls that flip its sign.

![bouncing-ball](bouncing-ball.gif)

### following-eyes

Reading input every frame — two eyes that track the real mouse cursor.

![following-eyes](following-eyes.gif)

## 🕹️ Phase 2 — Arcade Classics

### pong

Lesson 1 — W/S move your paddle, the right one is a tracking AI.

![pong](pong.gif)

### breakout

Lesson 2 — a brick grid as data, cleared one collision at a time.

![breakout](breakout.gif)

### snake

Lesson 3 — the whole snake is a vector of cells; growing is a conj.

![snake](snake.gif)

### space-invaders

Lesson 4 — a marching enemy formation, one bullet in flight at a time.

![space-invaders](space-invaders.gif)

### tetris

Lesson 5 — pieces as offset vectors, rotation as a coordinate transform.

![tetris](tetris.gif)

### flappy-bird

Lesson 6 — a title/playing/over state machine driven by a single key.

![flappy-bird](flappy-bird.gif)
